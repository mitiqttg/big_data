## Big Data Platforms: Introduction to Big Data Processing Frameworks

This repository contains my work for the course **Big Data Platforms: Introduction to Big Data Processing Frameworks**.  
The course explores scalable cloud computing technologies and the key algorithmic concepts that power them.

### Core Topics Covered:
- Distributed Computing  
- Warehouse-Scale Computers  
- Fault Tolerance in Distributed Systems  
- Distributed File Systems  
- Distributed Batch Processing with **MapReduce** and **Apache Spark (PySpark)**  
- Distributed Cloud-Based Databases
